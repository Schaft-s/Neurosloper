# Инструкция разметчику

До просмотра источника и чужих решений прочитайте запрос и документ целиком. На слайде прочитайте заголовок, тело и соседний слайд. Укажите, хватает ли материала, чтобы понять задачу автора. Выделите минимальную дословную цитату, которую предложили бы автору пересмотреть из-за шаблонного хода. Одной фразой назовите, что из-за этого потерял читатель. Если нужное свидетельство находится в другом месте, выделите его отдельно. Если требуется знать замысел, отметьте uncertain и запишите конкретный вопрос. Оценку происхождения текста не давайте. Пустая выдача — полноценное решение, если просмотрен весь объём.

Проверяйте оба направления. Вредный повтор не позволяет понять, чем отличаются пункты; полезный повтор может напоминать оператору обязательный срок. Отделяйте обычную фактическую ошибку от шаблонного обоснования. Родная модель, автор диалога и будущий стиль вам неизвестны. При повторном проходе сначала завершите собственную запись, затем откройте другую разметку. Сохраните обе исходные записи при согласовании.

Пример схемы одной записи: id документа, анонимный ID разметчика, complete / partial, список {block_id, start, end, quote, evidence, reason, decision}. Координаты кодовых точек Unicode, начало включительно, конец исключительно. Для слайда дополнительно slide_id и shape_id. Для пустого списка — просмотренные блоки и причина отсутствия замечаний. В data/genre_blind.jsonl уже есть 90 заданий; пустые поля для двух раздельных разметок формируются tools/review_forms.py. Это шаблоны для людей, пустая строка до их работы означает отсутствие разметки.

Оценка правок проходит отдельно от поиска. Ослепите имя модели, перемешайте порядок A/B независимо для каждой пары. Сначала отметьте, сохранён ли каждый атом требований и дословный якорь. Отдельно отметьте то, чего в источнике не было. Только среди допустимых версий выбирайте более подходящую по тону. Варианты ответа: A, B, одинаково приемлемы, ни один. Укажите причину, оценку удобства, время до решения и необходимость ручной доработки. Историческое продолжение WildChat не получает автоматически статус лучшего варианта.

Для теста восприятия с SlopFinder агрегируйте голоса по content_hash и показывайте число голосов, не только среднее. Нулевые оценки и шкалу порогов объявите заранее. В русских естественных реакциях user_feedback доступно только после получения замечания. Если пользователь просит добавить новый факт, разметьте это как отдельное изменение задания, чтобы не вознаграждать незапрошенное добавление фактов при обычной правке стиля.
