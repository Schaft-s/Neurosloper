На хосте проекта [рабочий веб-редактор](http://127.0.0.1:18477/) доступен с локальными правилами и добровольным модельным режимом. [Автономная сборка](http://127.0.0.1:18476/) использует только локальные правила.

Исполняемая версия находится в po_delu/. Архив po_delu_starter.zip сохраняет исходное состояние для сравнения. Сервису для работы не требуются каталог разметки или ключи ответов. Исследовательские данные доступны внутри комплекта.

## Первоначальная постановка и материалы команды
Откройте Idea.pdf для преподавателя, PITCH.md для устного выступления и Defense.html для интерактивной защиты идеи. PROJECT.md — постановка, архитектура, план работ, затраты и матрица критериев. RESEARCH.md — источники и уровни подтверждения. Для разработки — AGENTS.md и существующий po_delu_starter.zip. Наборы — в data/, фактические выходы прошлых проверок — в evaluation/. Этот комплект предназначен для команды; публичный репозиторий собирается из разрешённой части отдельно.

COUNTS.md содержит пересчитанные числа. Запуск из корня: python tools/verify.py. Команда python tools/review_forms.py /новый/каталог создаёт два отдельных задания для разметчиков; подробности в ANNOTATION.md. Для пересчёта прошлых метрик распакуйте соответствующий архив evaluation/ и следуйте его README/отчёту. Для воспроизведения первоначального состояния доступен po_delu_starter.zip. HTML работает без подключения к сети.

Схема происхождения данных: русские опубликованные сообщения извлечены из двух Parquet-шардов одной ревизии, перечисленной в data/SOURCES.md. Шард 0 содержит 43 564 строки; абсолютный row = shard_row + 43 564 × shard. У исходных наборов диалогов не всегда есть имена людей и права на дальнейшее публичное распространение производных. Для отладки пользователя и демонстрации преподавателю используйте вымышленные или согласованные примеры. При повторной сборке нужны lxml, pyarrow, снимок страницы Wikipedia и два исходных Parquet. Предвычисленные JSONL и скрипт проверки работают офлайн без этих зависимостей.

В tools/mine_feedback.py исходный поиск кандидатов рассчитывает на /tmp/realset и пишет промежуточную широкую выборку в /tmp/antiresearch. tools/assemble.py принимает путь к HTML и этому JSONL. Таблицы для оценщиков включают только отобранные безопасные по техническим фильтрам примеры; тексты из открытого интернета перед показом внешним пользователям нужно предварительно просмотреть. tools/holdout.py, tools/mine_register.py и tools/short_requests.py документируют процедуру отбора. Для register_pairs из промежуточной выдачи скрипта оставлены строки 4, 9–17 (нумерация с единицы); в них действительно запрошено изменение подачи предыдущего текста.
