# Проверка редакции после baseline-reviewed-v1

Исходное состояние — тег baseline-reviewed-v1. Прежние наборы v1 и первые два lockbox доступны для разработки. Стоимость оплаченных опытов входит в общий журнал проекта с лимитом 9,50 USD. Для OpenRouter используются только специально написанные вымышленные примеры.

## Гипотезы

1. Указание читательской задачи, различение объекта и голоса цитаты и проверка конкурирующих объяснений должны вернуть в выдачу содержательные замечания без лавины ложных тревог. Изучаются обнаружение с нуля и проверка по заранее указанному месту. Два независимых семейства дают первичные оценки. Отдельно измеряется, что меняет третий судья при расхождении.
2. Нахождение редакторского приёма можно улучшить, если поисковый запрос рассматривает также отношение между брифом и результатом, а от кандидата требует дословной, минимальной, но осмысленной цитаты. Отдельно регистрируются вклад семантического канала и Slopotron, все предложенные места и итог после проверки.
3. Смысл изменённой фразы можно проверять по тому, кто что делает, при каком условии и с какой силой обязательства. Это должно пропускать больше верных перефразировок, сохраняя отдельный жёсткий контроль неизменяемых строк и границы выбранного интервала.

## Решение о показе

Основные критерии для широкого пилота задаются до просмотра нового теста. Для обнаружения хотим вернуть не менее 60% размеченных находок при IoU ≥ 0,5, сохранить без ложного флага не менее 80% чистых документов и опередить исходную конфигурацию по F1 свободного поиска на тех же документах. При явно заданном месте ориентир — не ниже двух третей правильных трёхсторонних решений. Для реврайтера ориентиры — не пропустить ни одной внесённой смысловой ошибки и разрешить хотя бы две трети действительно изменённых допустимых редакций. Для обоих этапов отдельно сообщаются объём доступной выдачи, технические сбои и результат по полностью обработанным примерам. Семейства близких текстов считаются связанными, срезы по ним важнее числа отдельных бюллетеней.

Форматы и персональная память проходят через пользовательский веб-вход. Практическую редактуру также проверяем с выбором цитаты, генерацией и экспортом. Если критерии выполняет лишь часть решения, можно показывать проверенный сценарий с обозначением его ограничений. Результаты на уже раскрытом наборе не заменяют новый независимый тест. Повторные разработки после раскрытия ключей требуют отдельного отложенного материала; скорости или пользы для реальных пользователей эти эксперименты сами по себе не измеряют.
